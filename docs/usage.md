# Usage

```python
import optics_randomizer
```

Each module is self-contained; see docstrings for the API:

- `optics_randomizer.montecarlo_engine` — The core Monte Carlo engine functionality
- `optics_randomizer.ray_tracer` — Handles ray tracing operations for the lens system
- `optics_randomizer.experiment_runner` — Manages running Monte Carlo experiments with CI
- `optics_randomizer.stats_calculator` — Calculates statistics and confidence intervals from results
- `optics_randomizer.utils` — Miscellaneous utility functions for the project
- `optics_randomizer.main` — Entry point for running the Monte Carlo engine
